# Security Policy

## Supported versions

Security fixes are released for the latest published minor version of
`armature-core`. Upgrade to it before reporting an issue you found on an older
release.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/quinnjr/armature-core/security/advisories/new)
rather than in a public issue or pull request.

Include the affected version and feature flags, the transport involved
(`h1-backend`, hyper HTTP/1.1, HTTP/2, HTTP/3 or `micro`), and a minimal
reproduction. A request transcript or a fuzz crash file is ideal.

You can expect an acknowledgement within a week. Once a fix is released, the
advisory is published, with credit to the reporter unless they prefer otherwise.
